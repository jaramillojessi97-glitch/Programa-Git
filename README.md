# Safe Driving – GA7-220501096-AA3-EV01

## Descripción
Aplicación web académica para administrar vehículos, conductores y alertas de vencimiento documental.

## Tecnologías
- HTML5
- CSS3
- JavaScript
- Bootstrap 5.3.3
- Git y GitHub para versionamiento

## Ejecución
1. Descomprimir la carpeta.
2. Abrirla en Visual Studio Code.
3. Abrir `index.html` en un navegador. También se puede usar la extensión Live Server.
4. La interfaz carga Bootstrap desde CDN, por lo que se requiere conexión a internet para los estilos y componentes del framework.

## Funcionalidades implementadas
- Panel principal con indicadores.
- Registro y eliminación de vehículos.
- Registro y eliminación de conductores.
- Alertas de documentos vencidos o próximos a vencer (30 días).
- Reporte básico por marca y estado documental.
- Persistencia de demostración mediante localStorage.

## Observaciones
Esta entrega es un prototipo funcional de front-end. Los datos se almacenan localmente en el navegador; no incluye autenticación ni conexión a una base de datos de producción. Los registros iniciales son ficticios y se incluyen únicamente para demostrar el funcionamiento.

## Versionamiento
El proyecto debe publicarse en un repositorio propio de GitHub. Consultar `ENLACE_REPOSITORIO.txt` para registrar la URL real.
